# אספלט חי APK — משחק מרוצים, מוזיקה ודמויות

**יוצר ומפתח האפליקציה:** הרב דניאל כרייף שליט"א

## מה כולל ה-ZIP
- **משחק מרוצים עם מוזיקה ודמויות (`www/`):**
  - 3 דמויות נהגים (`עומר לוי`, `נועם כהן`, `אייל מזרחי`) עם תמונות בתיקיית `www/assets/`.
  - 3 רכבים (`GT קלאסי`, `טורבו אדום`, `אקו דריפט`) והגדרות תאורה (יום בהיר / שקיעה זהובה / לילה).
  - נגן מוזיקה מובנה (`סינת'-פופ` / `ים-תיכוני קצבי` / `כבוי`) + סאונד מנוע דינמי ב-WebAudio.
- **פרויקט Android מלא (`android_project/`)** מוכן לבניית `app-debug.apk`.
- **בנייה אוטומטית ב-GitHub Actions (`.github/workflows/build-apk.yml`):** מעלה את ה-APK כ-Artifact להורדה ישירה מ-GitHub.
- **סקריפט בנייה מקומי (`scripts/build_apk.ps1`):** לבנייה מקומית ב-PowerShell.
